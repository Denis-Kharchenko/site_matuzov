# MVP сайта Андрея Матузова

Одностраничный сайт-визитка для двух аудиторий:

- бизнес: корпоративное обучение, стратегические сессии, тренинги и форумы;
- частные клиенты: открытые события, лекции и индивидуальные запросы.

## Запуск

Для просмотра достаточно открыть `index.html` двойным кликом. Стили, скрипт и изображения подключаются относительными путями.

```bash
npm install
npm run dev
```

Сборка для публикации:

```bash
npm run build
```

Готовые файлы появятся в `dist/`.

## Что уже работает

- адаптивная версия для desktop и mobile;
- два маршрута пользователя;
- блок об Андрее, цифры, кейсы, медиагалерея и лента мероприятий;
- лид-магнит и форма обратного звонка;
- FAQ, мобильное меню и постоянная кнопка связи;
- состояния модальных окон, демо-отправка форм и уведомление об успехе;
- уважение к настройке `prefers-reduced-motion`.

## Telegram-бот для заявок

Для боевой версии форма должна отправлять данные не прямо в Telegram, а на защищенный серверный endpoint. Рекомендуемая схема:

1. Сайт отправляет имя, контакт, тип запроса и текст задачи на `/api/lead`.
2. Endpoint проверяет поля, ограничивает частоту запросов и блокирует спам.
3. Сервер вызывает Telegram Bot API. Токен хранится только в переменных окружения.
4. Андрей получает структурированное сообщение с кнопками `Взять в работу` и `Ответить`.
5. Заявка одновременно сохраняется в таблицу или CRM, чтобы ничего не потерялось.

Для MVP достаточно serverless-функции на Vercel, Netlify или Cloudflare Workers. Следующий этап можно сделать после получения токена бота и Telegram chat ID.
